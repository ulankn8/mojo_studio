# Проверка T-Studio на Windows

Займёт около 15 минут. Ничего не стоит: ИИ на этой проверке не вызывается.

## 1. Обновить программу

В PowerShell, в папке `mojo_studio`:

```
git pull
.venv\Scripts\pip install -e .
```

## 2. Самопроверка

```
.venv\Scripts\python -m toystudio.doctor
```

Каждая строка начинается со значка:

- `✓` — в порядке;
- `·` — для сведения, например есть ли видеокарта для кодирования и заданы ли ключи ИИ;
- `✗` — проблема.

В конце будет «Всё в порядке» или «Проблем: N». Если есть `✗`, пришлите скриншот всего окна.

Частые причины `✗`:

- **ffmpeg не найден или старый.** Нужна версия 7 или новее (сборка «full» с gyan.dev). Положите её в PATH или укажите папку в переменной: `setx TOYSTUDIO_FFMPEG_DIR "C:\ffmpeg\bin"`, затем перезапустите PowerShell.
- **Нет пакета.** Повторите `pip install -e .`.

## 3. Проверка в Premiere

```
.venv\Scripts\python -m toystudio.doctor --premiere D:\T-Studio-проверка
```

1. В папке `D:\T-Studio-проверка` появятся клипы, `T-Studio проверка.xml`, `look.cube`, `образец.mp4` и `ПРОВЕРКА.txt`.
2. Откройте XML в Premiere (File → Import).
3. Пройдите 7 пунктов из `ПРОВЕРКА.txt`: переходы, замедление, наезд, световая накладка в режиме Screen, музыка, LUT.
4. По каждому пункту ответьте «да» или «нет». Где «нет», пришлите скриншот.

## 4. Настоящая свадьба

1. Откройте проект в T-Studio.
2. Соберите Love Story и экспресс, нажмите «Сохранить видео».
3. Откройте получившийся XML в Premiere и проверьте:
   - медиа подхватилось без поиска файлов;
   - замедления и переходы на месте;
   - ролик проигрывается.
4. Если что-то не так, напишите время в ролике и что видно.
