# Той Студия (mojo_studio)

Десктопная программа для Windows, которая автоматически монтирует тойские видео: свадьбы, тои, юбилеи. Анализ видео идёт локально, облачная модель получает только текст и составляет план монтажа, монтажёр правит черновик и экспортирует клип. Реализация — Python 3.12 + PySide6.

## Виды монтажа и дорожки (0.1.1)

Новый проект начинается с экрана «Что монтируем?». От выбранного вида зависят зоны (дорожки), по которым раскладываются файлы:

| Вид | Дорожки |
| --- | --- |
| Свадьба · экспресс-видео | съёмка до ресторана (камеры вперемешку), музыка |
| Свадьба · полный фильм | до ресторана; ресторан: V1 основная камера, V2 подсъёмка, A1 речь с пульта; музыка |
| Love Story, рекламный ролик | вся съёмка вперемешку, музыка |
| Подкаст или интервью | V1, V2, A1 речь с микрофонов, музыка |
| Той, юбилей и другое | видео и музыка, как в 0.1.0 (старые проекты открываются в этом виде) |

- Речь с пульта (WAV/MP3) анализируется: звук и огибающая, участки речи, звуковые события. Сцены, качество кадра и моменты у неё не считаются.
- Синхронизация идёт по дорожкам. Эталон — запись с пульта: рекордер режет одну запись на файлы, они выкладываются подряд в порядке имён. Основная камера и подсъёмка встают на её время. Без записи эталон — самая длинная основная камера. Съёмка до ресторана не синхронизируется: у неё нет общего времени.
- Библиотеку музыки можно добавить папкой («Выбрать папку»).
- В базе: `project.format` и `media.role` (миграция `0004_roles.sql`).

## Черновик ресторана для Premiere (0.1.2)

После анализа проекта «Свадьба · полный фильм» или «Подкаст» на экране анализа появляется кнопка «Собрать черновик для Premiere». Она собирает черновик за доли секунды, сохраняет его в проект (вариант монтажа «Ресторан · черновик») и пишет `<проект>/export/<название> · ресторан.xml`. Этот файл открывается в Premiere Pro через «Файл → Импорт» (формат FCP7 XML).

Как собирается черновик (правила взяты из разбора готового фильма монтажёра):
- Звук — непрерывная запись с пульта. Если её нет, берётся звук основной камеры.
- Камеры чередуются: основная около 5,4 с, подсъёмка около 4,5 с. Склейка подтягивается к паузе между фразами. Камера с трясущимися или размытыми кадрами отдаёт свой план другой.
- Тосты не режутся. Паузы длиннее 10 с убираются. Музыка дольше 30 с считается танцем: один длинный план подсъёмки, не больше 5 мин.
- В Premiere: V1 — основная камера, она идёт и под вставками; V2 — подсъёмка; A1/A2 — звук с пульта.

Код: `engine/edit/restaurant.py` (правила), `engine/export/premiere_xml.py` (XML), `jobs/restaurant_draft.py` (сборка из проекта). У `Timeline` появилась дорожка `speech`.

## Запуск

Нужно:

- Python 3.12;
- ffmpeg и ffprobe версии 7 или новее — в `PATH` или в папке, указанной в переменной `TOYSTUDIO_FFMPEG_DIR`.

```sh
python -m venv .venv
.venv/bin/pip install -e ".[dev]"      # Windows: .venv\Scripts\pip install -e ".[dev]"
python -m toystudio.app.main
```

Где лежат данные:

- проекты — `%USERPROFILE%\Videos\Той Студия` (macOS: `~/Movies/Той Студия`, Linux: `~/Videos/Той Студия`);
- список проектов и скорости анализа — `%APPDATA%\ToyStudio\app.db` (вне Windows: `~/.toystudio/app.db`);
- `TOYSTUDIO_HOME=<папка>` кладёт и проекты (`<папка>/projects`), и `app.db` в одну папку — для тестов и переносного запуска.

Модели (Silero VAD и YAMNet в формате ONNX) лежат в репозитории, в `toystudio/engine/models`; скачивать ничего не нужно. Проверить контрольные суммы: `python tools/fetch_models.py --verify` (без `--verify` скрипт докачает недостающие или повреждённые модели).

Тесты: `pytest` (сквозной тест `tests/app/test_flow_phase2.py` запускает настоящий анализ и требует ffmpeg 7+).
